# 보고서 화면 자산

`report.html`과 `report.css`는 고정된 보고서 구조와 스타일입니다. `report_generator.py`가 검증한 분석 데이터만 템플릿 변수로 채웁니다. 보고서를 생성할 때 CSS를 출력 폴더에 복사하므로 생성된 HTML은 같은 폴더에서 바로 열 수 있습니다.

발견사항은 심각도 순서로 표시합니다. 요약 목록과 상세 항목에 취약점 종류, 코드 위치, 검증 상태를 함께 보여줍니다.

보고서 문장을 생성하는 Codex에는 HTML이나 CSS를 요청하지 않습니다. 같은 세션 내용·모델·프롬프트 버전으로 보고서를 다시 만들면 세션의 요약 캐시를 재사용합니다.
