Identify external components using local product, exact version or build, package identity, and relevant configuration evidence. If network access is explicitly enabled, consult primary vendor or project advisories and original CVE records; record URLs and applicability reasoning. If offline, mark external lookup pending and do not invent a CVE. A name or version string alone never confirms a vulnerability; inspect whether affected code is actually included and enabled. Ask Detective only when reachability or runtime behavior of an applicable issue requires testing. Never upload firmware or extracted content to an external service.
